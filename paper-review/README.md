# paper-review

論文原稿を添削するスキル（paper-review）．
信学技報，情報処理学会の研究報告・シンポジウム（ComSys など），IEEE論文・国際会議，大会原稿，卒論・修論の原稿を，体裁から主張の強さまで決まった順で確認し，変更前／変更後の表で指摘を返す．
あらまし（Abstract）は，電子情報通信学会・情報処理学会・人工知能学会の字数・語数の上限，構成と分量配分，主語の目安（3学会の論文誌の調査），英文の時制を目安にして確認する．
指摘の理由には，根拠とする書籍・資料（『理科系の作文技術』，電子情報通信学会編『学術論文の書き方・発表の仕方』，通信ソサイエティマガジンの「論文の書き方講座」など）のページを示す．

中身は `skills/paper-review/SKILL.md` にある．

koita-persona（小板として話すスキル koita-ai）とは別のスキルで，併用できる．以前のフォルダ名は koita-ai-v2．

## 入れ方

### Claude Code

このフォルダごと手元に置き，起動時に指定する．

```
claude --plugin-dir /path/to/paper-review
```

スキルだけ使うなら，`skills/paper-review/` を `~/.claude/skills/` に置く（`~/.claude/skills/paper-review/SKILL.md` になる形）．

### claude.ai（Web，デスクトップ）

`skills/paper-review/` フォルダを zip にする（フォルダが zip の根に来る形）．
Customize > Skills で「+」，「Create skill」，「Upload a skill」の順に進んで上げ，一覧でオンにする．

## 使い方

原稿のPDF・Word・LaTeXを渡して，「原稿見て」「投稿前にチェックして」と頼む．
結果は `skills/paper-review/assets/review-template.html` の形のHTML（研究室の卒論計画書レビューと同じ見た目）で返る．研究のコアの図，よい点，最優先で直すべき指摘3〜5件，確認項目ごとの指摘の表，検討して欲しいこと，次のアクションが並び，表の最右列に優先度（必須＝赤，推奨＝橙，任意＝灰）が付く．
卒業論文の場合は，研究室の卒業論文チェックシート（①書式，②論文タイトル，③全体のストーリーや章構成，④文章や段落，⑤単語や句，⑥数式，⑦図表や箇条書き，⑧参考文献）の全項目の結果（○／×／本人確認／該当なし）も返る．
