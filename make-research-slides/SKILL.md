# 研究発表スライド作成

学会発表・論文発表・ゼミ発表のスライドを、`pptxgenjs` で .pptx として生成し、PDF も出力する。 スライドの目的は装飾ではなく伝達。整理とバランスを最優先し、足し算より引き算で作る。

全ルールの詳細は `references/guidelines.md` にある。作業を始める前に必ず読む。 実装のひな形は `assets/build_template.js`、完成例は `examples/sample_uav_talk.pdf`。

## 進め方

1. **ヒアリング**：分かっていないことだけ聞く。  
   - 発表の種類（口頭・ゼミ・輪講・ポスター）、発表時間と質疑時間  
   - 学会名・聴衆、言語、アスペクト比（既定 16:9）、会場PCと指定ファイル形式  
   - 素材（論文PDF・原稿・図・実験データ・参考文献リスト）  
2. **素材を読む**：論文や原稿があれば先に読み、章立て・貢献・実験条件・数値・参考文献を抜き出す。  
3. **構成案を先に出す**：各スライドの「タイトル（主張文）」「強調する1箇所」「載せる図」を一覧にして合意を取る。  
4. **生成**：`assets/build_template.js` をコピーして `slides/build_<発表名>.js` を作り、内容を差し替えて実行する。  
5. **QA**：PDF に変換し、全ページを画像にして目視確認する（下記）。問題を直して再生成する。  
6. **納品**：`slides/<発表名>.pptx`、同名の `.pdf`、生成スクリプト。発表原稿はスピーカーノートに入れる。

## 必ず守るルール（要約）

- **構成**：タイトル → 本日の流れ → 背景 → 先行研究（系統ごとに1枚＋位置づけ1枚）→ 目的・貢献 → 提案手法 → 実験（条件）→ 結果（数値の表・グラフ）→ 考察 → まとめ・今後の課題 → 参考文献 → 予備スライド。  
- **1スライド1メッセージ**。タイトルはラベル（「実験結果」）ではなく主張文（「閉ループ制御で高度誤差が小さくなった」）にする。句点なし、2行以内。  
- **強調は1スライド1箇所**。  
  - 骨格＝メインカラー：タイトル・見出し・番号の丸・カードの薄い塗り・図のブロック。全スライド同じ使い方なので強調に数えない。  
  - 強調＝アクセントカラー：一番伝えたい1つだけ。2箇所以上になったら絞るか、スライドを分ける。  
- **情報量**：論文発表として必要な手順・パラメータ・条件・評価指標・数値は載せる。本文は最大5項目・各1〜2行、図の横は3〜4項目まで。超えたら分割するか予備スライドへ。  
- **文字**：ゴシック体（既定メイリオ）。本文18pt以上、タイトル24pt、見出し20pt、注記・出典のみ12〜14pt。  
- **色**：白黒（グレースケール）基調。背景は白、本文 \#3C3C3C、骨格はほぼ黒 \#262626 とグレー。色は強調用の緑 \#1F8A4C だけ。グラフは見てほしい系列だけ緑、他はグレー。  
- **レイアウト**：左→右・上→下の視線に沿う。整列と等間隔の余白。タイトル下の装飾ライン、端の帯・ストライプは使わない。ページ番号を右下に入れる。  
- **デザインの細部**：  
  - 余白でグループを示す（見出し→本文の余白 ＜ グループ間の余白）。  
  - 枠線で囲まず、薄い面を敷いてまとめる。表は横線のみで、列・行の区別は色を敷く。  
  - 1行は30字程度まで。文字に影・下線を付けない。書体は1種類。  
  - フッターに章ナビ（現在の章だけメイン色）。表紙に装飾は入れない。  
- **アイコン**：分かりやすくなる場所（システム構成図・処理の流れのブロック）にだけ、1発表1〜2枚まで。見出し・目次・カード・表紙には使わない。線だけのシンプルなアイコン（Tabler Icons）をメイン1色で。  
- **入れないもの**：謝辞、研究室紹介、「本日の流れ」以外の細かい目次。  
- **事実の扱い**：データにない数値・誇張した数値を書かない。未確定の値は `[要確認]` にする。  
- **文献の扱い**：実在を確認した文献だけ引用する（ユーザーの論文の参考文献リスト、または検索して DOI・書誌情報を確認したもの）。確認できなければ `[要記入]` にし、著者・年・タイトルを推測で書かない。

## 実装メモ（pptxgenjs）

- `pres.layout = "LAYOUT_16x9"`（10 × 5.625 インチ）。座標がはみ出しても切られないので注意する。  
- レイアウトは `TITLE` / `CONTENT` / `APPENDIX` を `defineSlideMaster()` で定義し、タイトルは placeholder で入れる。フッターとページ番号はレイアウト側に置く。  
- 色は `#` なしの6桁HEX。  
- **日本語の字形**：pptxgenjs は `lang="en-US"`・中国語の文字セットで書き出すため、漢字が中国語の字形になることがある。書き出し後に必ずひな形の `fixJapanese()` を実行する（lang を ja-JP、charset を \-128、テーマの東アジア用フォントを設定）。オプションのオブジェクトは使い回さない（pptxgenjs が中身を書き換えるため）。  
- テキストは `isTextBox: true`、図形と揃える箇所は `margin: 0`。箇条書きは `bullet` オプションを使い、「•」を文字で書かない。  
- グラフは `addChart()` のネイティブグラフにし、軸タイトルに単位を付ける。  
- アイコンは `react-icons/tb` の SVG を `sharp` で PNG にして `addImage()` で貼る。使うアイコンと色は最初に `preloadIcons()` にまとめて登録する。  
- `pres.addSection()` で構成ごとにセクションを付け、各スライドに `slide.addNotes()` で発表原稿（1枚150〜250字）を入れる。

## QA

1. `soffice --headless --convert-to pdf slides/<発表名>.pptx` で PDF にする。  
2. `pdftoppm -r 60 -png <pdf> pg` で画像にし、全ページを見る。  
3. 確認すること：  
   - 文字のはみ出し・重なり、タイトルが1文字だけ次の行に落ちていないか  
   - アクセントカラーが各スライド1箇所だけか  
   - 本文18pt以上か、整列と余白が揃っているか  
   - `pdffonts` で中国語用フォント（`NotoSansCJKsc` など）が使われていないか  
   - 引用したものは参考文献が記載されているか  
4. 環境にメイリオがないとプレビューは代替フォントになる。実際のメイリオは字幅がやや広いので、テキスト枠には余裕を持たせる。

最後に `references/guidelines.md` の §9 チェックリストを確認してから納品する。
